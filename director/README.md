# Файл режиссёра (director/)

Инструкции для локальной языковой модели (Ollama и т. п.), которая превращает
«сырое» пожелание пользователя в правильный промпт для конкретной модели.

Как это будет работать:
1. Пользователь надиктовал или написал как угодно и на любом языке: «мужик на острове рассказывает про костёр, весёлый».
2. Whisper сразу переводит речь на английский (уже работает: «Диктовка → английский» в настройках).
3. Стол берёт `director.md` (общие правила) + файл модели из workflow (например, `ltx2.md`)
   и отправляет локальной LLM вместе с текстом и списком входных файлов (картинка, звук, длительность).
4. LLM возвращает готовый промпт в структуре модели → он подставляется в поле «Промпт» виджета.
   Пользователь видит результат и может поправить перед запуском.

Какой файл брать: в workflow можно указать `"guide": "ltx2"`. Если не указан —
стол угадывает по нодам (LTXV* → ltx2, Flux → flux, ACE-Step → music …).

Файлы:
- `director.md` — общие правила для LLM (роль, формат ответа, что нельзя).
- `ltx2.md` — LTX-2 / LTX-2.3: видео со звуком, синхронизация губ.
- `_template.md` — шаблон, чтобы добавить свою модель.

Всё работает локально и с открытыми моделями — подходит для номинации Open Weights.
